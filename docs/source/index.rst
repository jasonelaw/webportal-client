webportal-client: Python Client for Aquarius WebPortal
==============================

A Python client for
`Aquarius WebPortal <https://aquaticinformatics.com/products/aquarius-environmental-water-data-management/aquarius-webportal-time-series/>`_
. Provides a synchronous client based on the requests package and an asynchronous client based on httpx.
